# React + TypeScript + Vite = Chess App
Written by Vien Pham, complete with UI and AI engine.
Currently, the main AI algorithm is incomplete, and Stockfish is being used. Will add this later.


How to play:
- Clone the code, install npm with "npm install"
- then do npm run dev. You can now run the game on localhost 5173
- Choose to play either against AI or another person. Enjoy!
